# Hire4Event Website

A professional, multi-page event management website built using HTML, CSS, and JavaScript.

## About the Project

Hire4Event is an event management website project designed to help users explore event services and plan their events. The website features a clean black-and-white design and responsive layouts.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Website Pages

- Home
- Services
- Solutions
- Marketplace
- Resources
- Company
- About
- Contact
- Plan Your Event

## Features

- Professional black-and-white design
- Responsive navigation menu
- Mobile-friendly layout
- Event service cards
- Event planning call-to-action sections
- JavaScript-powered mobile menu
- Automatic footer year
- Event enquiry page layout

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your web browser.
4. Alternatively, use the Live Server extension in VS Code.
5. Explore the website using the navigation menu.

## Installation

No additional packages are required for the basic HTML, CSS, and JavaScript version.
